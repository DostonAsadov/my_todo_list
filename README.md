# Название твоего проекта (например, Task Management API)

Краткое описание: REST API для управления задачами, написанное на Laravel 11.

## Требования 🛠️
* PHP 8.4+
* Composer
* MySQL 8.0+

## Установка 📥

1. **Клонируйте репозиторий:**
   
   ```git clone <ссылка_на_твой_репозиторий>```
   
   ```cd <название_папки>```

2. **Установите зависимости:**

    ```composer install```

3. **Настройте окружение:**

    ```cp .env.example .env```

4. **Настройте базу данных:**
   Откройте файл `.env` и укажите данные вашего подключения к MySQL:
   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=название_вашей_бд
   DB_USERNAME=ваш_логин
   DB_PASSWORD=ваш_пароль


5. **Генерация ключа и миграции:**

    ```php artisan key:generate```
    ```php artisan migrate```

6. **Запуск проекта**

    ```php artisan serve```

    ///Проект будет доступен по адресу: http://127.0.0.1:8000


## Тестирование (Postman) 🧪

Для проверки работы API в корне проекта подготовлена коллекция Postman: `my_todo_list.postman_collection.json`.

### Как запустить:
1. Импортируйте файл коллекции в Postman (кнопка **Import**).
2. Настройте **Variables** (переменные) коллекции или окружения:
   * `base_url`: `http://127.0.0.1:8000`
3. Все запросы используют префикс `/api/v1/`.

### Основные эндпоинты:

| Метод | Эндпоинт | Описание | Особенности |

| **GET** | `/api/v1/tasks` | Список всех задач | Поддерживает просмотр всех записей |
| **POST** | `/api/v1/tasks` | Создание новой задачи | `title` (req), `description`, `status` |
| **GET** | `/api/v1/tasks/{id}` | Просмотр одной задачи | Возвращает 404, если задача не найдена |
| **PUT** | `/api/v1/tasks/{id}` | Обновление задачи | Можно обновить `title` (req), `description` или `status` |
| **DELETE** | `/api/v1/tasks/{id}` | Удаление задачи | Навсегда удаляет запись из базы |


### Структура данных (JSON):
* `title` (string) — Название задачи. **Обязательное поле.**
* `description` (string) — Подробное описание. Опционально.
* `status` (string) — Текущий статус. Опционально (по умолчанию устанавливается системой).
